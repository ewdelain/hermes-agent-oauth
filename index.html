Hermes Agent (personal use)

This is a private, single-user setup of the open-source Hermes Agent, running on its owner's own computer. It uses Google OAuth so the owner can ask the agent to read, organize and send the owner's own Gmail, and to view and manage the owner's own Google Calendar.

It is not a public service and is not offered to anyone else.

這是個人自用的 Hermes Agent，在擁有者自己的電腦上執行，透過 Google OAuth 存取擁有者本人的 Gmail 與 Google 日曆，不對外提供服務。
