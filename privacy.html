Privacy Policy

Last updated: 2026-10-20

"Hermes Agent (personal)" is a private setup used only by its owner, on the owner's own computer.

  • Data accessed: the owner's own Gmail messages and labels, and the owner's own Google Calendar events, only when the owner asks the agent to do a task.
  • Storage: OAuth tokens and any retrieved data stay on the owner's local computer. This app runs no server and keeps no copy elsewhere.
  • Sharing: data is never sold, shared with third parties, or used for advertising. Content may be processed by the AI model the owner configures for the agent (a locally running model by default).
  • Google API Services: use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions.
  • Contact: use the support email shown on the Google sign-in consent screen for this app.

隱私權政策（中文）

  • 存取的資料：僅限擁有者本人的 Gmail 郵件與標籤、Google 日曆活動，且只在擁有者要求執行任務時存取。
  • 儲存：OAuth 憑證與取得的資料只存在擁有者自己的電腦，本應用程式沒有伺服器，也不在其他地方留存。
  • 分享：不出售、不提供給第三方、不用於廣告。內容可能由擁有者為 Agent 設定的 AI 模型處理（預設為本機模型）。
  • 遵守 Google API 服務使用者資料政策（含「有限使用」規定）。
  • 可隨時在 myaccount.google.com/permissions 撤銷存取權。
